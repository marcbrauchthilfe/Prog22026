**Git-Spiel**

1. Problemloses Mergen möglich. Man hat auf den beiden Branches verschiedene Dateien verändert, also kann man end problemlos in master mergen.
2. Problemloses Mergen möglich. Man hat auf den beiden Branches zwar in derselben Datei etwas verändert, dabei aber unterschiedliche Zeilen verändert, also kann man end problemlos in master mergen.
3. Wenn die Änderungen nicht identisch zu der im Branch end sind, gibt es Merge-Konflikte. Sind die änderungen jedoch identisch kann man end problemlos in master mergen. Den Konflikt löst man, indem man entscheidet welche Version der beiden man behalten/übernehmen möchte. Das kann man entweder in der UI von IntelliJ machen oder über die Konsole mit git checkout --ours/--theirs <datei> - git add <datei> - git commit
